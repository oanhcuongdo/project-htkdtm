# Font và biểu tượng của giao diện auth

- Be Vietnam Pro được cài qua `@fontsource/be-vietnam-pro`, build cùng ứng dụng. Giữ kèm giấy phép SIL Open Font License tại `BE-VIETNAM-PRO-LICENSE.txt`.
- `material-symbols-rounded.ttf` là subset 13 Material Symbols Rounded, trục `opsz=24,wght=400,FILL=0,GRAD=0`, tải từ Google Fonts CSS API. Giữ kèm `MATERIAL-SYMBOLS-LICENSE.txt` (Apache 2.0).
- Icon: arrow_back, arrow_forward, check, check_circle, close, info, lock, mail, person, restaurant, shield, visibility, visibility_off.

Nguồn: [Material Symbols của Google](https://developers.google.com/fonts/docs/material_symbols), [repository chính thức](https://github.com/google/material-design-icons). Ứng dụng không gọi Google Fonts lúc người dùng mở trang.
